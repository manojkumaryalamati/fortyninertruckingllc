Step 3: Configure classic Firebase Hosting

In the real app root, create or replace firebase.json with:

{
  "hosting": {
    "public": "dist",
    "ignore": [
      "firebase.json",
      "**/.*",
      "**/node_modules/**"
    ],
    "rewrites": [
      {
        "source": "**",
        "destination": "/index.html"
      }
    ]
  }
}

This is required for Vite SPA routing so direct refresh on /services, /fleet, /careers, and other routes works.

Step 4: Configure Firebase project

Create or update .firebaserc in the real app root:

{
  "projects": {
    "default": "fortyninertruckingllc"
  }
}

Step 6: Fix BASE_PATH safely

Open vite.config.ts.

If BASE_PATH is required, make it safe:

const BASE_PATH = process.env.BASE_PATH || "/";

Make sure Vite uses:

base: BASE_PATH

Do not throw an error if BASE_PATH is missing.

From the real app root, run:
